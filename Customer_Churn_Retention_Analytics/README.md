# Customer Churn & Retention Analytics

## Tech Stack
- MySQL
- Python (Pandas, Matplotlib)
- Power BI

## Business Objective
Understand why customers churn, identify high-risk segments, and quantify revenue at risk.

## Project Structure
data/customer_churn.csv      -> main dataset
sql/churn_analysis.sql       -> MySQL analysis queries
python/eda_analysis.py       -> cleaning + EDA
powerbi/dax_measures.txt     -> Power BI measures
docs/powerbi_dashboard_steps.md -> complete dashboard instructions
